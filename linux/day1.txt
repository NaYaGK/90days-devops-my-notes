============= >> .ssh/config file setup << ==========
once after creating ec2 instance amazon server then in local setup (your pc) open terminal and type "cd ~/.ssh" it will enter into .ssh folder (user can create "config" at any paths like downloads, documents and other) 

create config file we can use cat/vim/nano 

Host devops-ec2 (user can keep any name)
HostName 65.2.190.72 (public ip address)
user ec2-user (by default ec2-user will be username)
Other AMIs may use different usernames, such as:
Ubuntu → ubuntu
Debian → debian
CentOS → centos

IdentityFile ~/Downloads/formac.pem (pem [ssh key] file location)
StrictHostKeyChecking no
Prevents SSH from asking whether to trust the server the first time you connect.
It automatically accepts the server's host key.
This is convenient for testing, but for production environments it's generally better to leave host key checking enabled to help protect against connecting to an unexpected server.

how to use it 
once we save configuration
we can type in terminal "ssh devops-ec2"
if we save config file in downloads we must tell ssh where to find it
ssh -F ~/Downloads/config devops-ec2
Here, -F specifies an alternate SSH configuration file.
better recommandation to create in /.ssh folder 

instead of typing ssh -i ~/downloads/formac.pem ec2-user@85.2.190.72
